1 Event Table

Key application events, trigger conditions, triggering actors, and automated system responses.

Event Name Trigger / Condition Actor System Response
UserSignedUp / UserLoggedIn User submits email/password or Google OAuth in Auth.tsx User authService.ts authenticates with Firebase Auth, provisions or retrieves users/{userId} document in Firestore, loads user profile & contacts into state.
TripStarted User fills destination, transport mode, check-in interval, and clicks "Start Safe Trip" in StartTrip.tsx User tripService.startTrip() creates a document in trips/{tripId} with status: 'active', captures initial GPS coords, creates guardian tracking link, and initializes periodic check-in timer.
TripLocationUpdated Geolocation watcher fires with updated latitude/longitude Device GPS / User tripService.updateTripLocation() updates currentLocation and appends coordinate to routeHistory in Firestore trips/{tripId}.
CheckInPromptDue Elapsed time since last check-in reaches checkInIntervalMinutes System Timer (ActiveTrip.tsx) System plays alert chime, activates high-visibility check-in banner, and begins countdown to unacknowledged timeout.
CheckInAcknowledged User presses "I'm Safe / Check In" button in ActiveTrip.tsx User tripService.acknowledgeCheckIn() updates lastCheckIn timestamp in Firestore and resets the check-in interval timer.
CheckInMissed User fails to acknowledge check-in before unacknowledgedTimeoutMinutes expires System Timer (ActiveTrip.tsx) Automatically triggers triggerSOSAlert() with trigger type "timeout" and dispatches emergency alerts to all registered contacts.
SOSTriggered User presses red SOS button, uses 4-click hardware key shortcut, or trigger modal completes User tripService.triggerSOSAlert() updates isSOS: true on trip, updates user status, logs SOS event with high-accuracy GPS, captures 10s audio evidence, and sends notifications.
WakePhraseDetected Continuous Web Speech API matches configured wake phrase (e.g. "help me", "मदद करो", "वाचवा") Web Speech API / Voice voiceSosService.ts fires callback, plays voice recognition confirmation chime, and triggers immediate emergency SOS alert.
FallDetected Accelerometer detects sudden high-g spike (>32 m/s²) followed by stillness Accelerometer / devicemotion fallDetectionService.ts triggers FallDetectionModal, plays emergency pulse beep, starts 15s cancel countdown, and fires SOS if not disarmed.
FakeCallInitiated User clicks floating call button or triggers via triple-tap / settings User FakeCallModal.tsx renders full-screen incoming call UI, loops synthesized ringtone via Web Audio API, and transitions to connected timer on answer.
TripEnded User clicks "End Trip / Arrived Safely" in ActiveTrip.tsx User tripService.endTrip() marks trip status: 'completed', isSOS: false, sets endTime, cleans up GPS watchers and background audio recorders.

6 Activity Diagram

Trip state lifecycle, check-in validation logic, auto-timeout protection, and safe disarming.

flowchart TD
    Start([User Initiates Safe Trip]) --> InputForm[Enter Destination, Mode & Interval]
    InputForm --> ClickStart[Click 'Start Safe Trip']
    
    ClickStart --> InitTrip[tripService.startTrip: Save Firestore & Track GPS]
    InitTrip --> StartTimer[Initialize Check-In Countdown Timer]

    StartTimer --> MonitorState{Trip In Progress}

    %% Tracking Branch
    MonitorState -->|GPS Movement| UpdateGPS[Update Live Location & Breadcrumb]
    UpdateGPS --> MonitorState

    %% Check-In Timer Branch
    MonitorState -->|Interval Elapsed| PromptCheckIn[Display Check-In Prompt & Play Chime]
    PromptCheckIn --> StartAckCountdown[Start Grace Period Countdown]
    
    StartAckCountdown --> CheckInDecision{Did User Acknowledge?}
    CheckInDecision -->|Yes: Clicked 'I am Safe'| ResetTimer[tripService.acknowledgeCheckIn]
    ResetTimer --> MonitorState

    CheckInDecision -->|No: Timer Expired| TimeoutTrigger[Auto-Trigger SOS: Reason 'timeout']

    %% Parallel Detection
    MonitorState -->|User Presses SOS Button| ManualTrigger[Trigger Manual SOS]
    MonitorState -->|Voice Matches Wake Phrase| VoiceTrigger[Trigger Voice SOS]
    MonitorState -->|Impact Spike Detected| FallTrigger[Start 15s Fall Countdown]
    
    FallTrigger --> FallCanceled{User Disarmed?}
    FallCanceled -->|Yes: Clicked 'I am OK'| MonitorState
    FallCanceled -->|No: 15s Expired| ImpactSOS[Trigger Fall Impact SOS]

    %% SOS Execution
    ManualTrigger --> ExecuteSOS[Execute triggerSOSAlert]
    VoiceTrigger --> ExecuteSOS
    TimeoutTrigger --> ExecuteSOS
    ImpactSOS --> ExecuteSOS

    ExecuteSOS --> RecordAudio[Record 10-Second Audio Evidence]
    ExecuteSOS --> MarkFirestore[Set trip.isSOS = true & user.activeSOS = true]
    ExecuteSOS --> SendAlerts[Dispatch Emails with Live GPS Link to Contacts]
    RecordAudio --> AttachEvidence[Attach Audio to Trip in Firestore]
    AttachEvidence --> SOSActiveState[Display Emergency QR Badge & 1091 Quick Dial]

    %% Completion
    MonitorState -->|User Arrives| ClickEnd[Click 'End Trip / Arrived Safely']
    SOSActiveState -->|Resolved / Safe| ClickEnd
    ClickEnd --> CompleteTrip[tripService.endTrip: status = 'completed']
    CompleteTrip --> StopSensors[Stop GPS Watcher, Voice Recognition & Audio]
    StopSensors --> End([Trip Completed & Logged to History])
